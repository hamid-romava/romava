## Public website releases only

For public studio website work, read `docs/studio-release-process.md` and `docs/studio-versions.md` first. Follow the ClickUp target-version labels and `site-vN.M` Git tags described there. Inspect existing changes before editing, test each complete change, and commit only its own files. Bump the public-site version only when closing a release; deploy and publish its tag only when the user requests publication. Verify the production domain before marking a release published. This workflow does not change or version the client/team dashboards.
