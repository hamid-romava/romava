# نسخه‌های داشبورد روماوا

| نسخه | تگ گیت | تغییر |
| --- | --- | --- |
| 1.3 | `dashboard-v1.3` | پاسخ متنی در بررسی و تمدید، آمادگی ضبط و یادآوری آفیش برای مشتری، تست مایک و ثبت تایم پرتی برای تیم |
| 1.2 | `dashboard-v1.2` | احتساب گزارش سیستمی در سهم آچار فرانسه و جمع تیم اجرایی |
| 1.1 | `dashboard-v1.1` | اصلاح سهم کارگردان و جذب، افزودن درصد شخص از سهم روماوا، راهنمای اکسپلور و بند تازهٔ متمم فرهنگ‌نامه |
| 1.0 | `dashboard-v1.0` | شروع نسخه‌گذاری مشترک پنل مشتری و تیم |

برای هر تغییر داشبورد، یک کامیت با توضیح مشخص ثبت می‌کنیم. هر نسخهٔ داشبورد می‌تونه شامل چند کامیت باشه.

- تغییرهای کوچک، عدد بعد از نقطه رو جلو می‌برن. مثلاً 1.0 → 1.1.
- بازطراحی اساسی، عدد قبل از نقطه رو جلو می‌بره. مثلاً 1.3 → 2.0.
- موقع بستن نسخه، شماره رو در `lib/dashboard-navigation.ts` و جدول بالا به‌روز کن. تگ `dashboard-vX.Y` رو روی کامیت نسخه بزن و بعد از انتشار، شمارهٔ منوی هر دو پنل رو روی دامنهٔ اصلی چک کن.
