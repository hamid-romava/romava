# نسخه‌های سایت عمومی روماوا

نسخهٔ فعلی: **3.9**

- بازطراحی اساسی، عدد قبل از نقطه را یک واحد جلو می‌برد و عدد بعد از نقطه را صفر می‌کند. مثال: 3.6 → 4.0.
- هر انتشار کوچک سایت عمومی، مثل اصلاح متن، لینک یا جای دکمه، عدد بعد از نقطه را یک واحد جلو می‌برد. مثال: 3.6 → 3.7.
- انتشارهای محدود به داشبورد داخلی در این شماره‌گذاری حساب نمی‌شوند. لینک نسخه‌های آرشیوی در فوتر و منوی عمومی نمایش داده نمی‌شود.
